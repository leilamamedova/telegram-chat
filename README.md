# Telegram Chat

Чат на React для отправки и получения текстовых сообщений в Telegram через [GREEN-API](https://green-api.com/telegram).

## Что умеет

- вход по `idInstance` и `apiTokenInstance`;
- создание чата по номеру телефона или по `@username`;
- отправка текстовых сообщений;
- получение ответов собеседника прямо в чате.

## Стек

React 18, TypeScript, Vite, Zustand, обычный CSS.

## Как запустить

1. В личном кабинете GREEN-API создайте инстанс Telegram и авторизуйте его.
2. В настройках инстанса включите уведомления о входящих сообщениях. Поле `webhookUrl` оставьте пустым.
3. Скопируйте `idInstance` и `apiTokenInstance`.
4. Установите зависимости и запустите проект:

```bash
npm install
npm run dev
```

5. Откройте адрес из терминала (обычно http://localhost:5173) и войдите с данными инстанса.
6. Введите номер получателя в международном формате (например, `79001234567`) или его `@username` и нажмите «Создать чат».
7. Напишите сообщение. Когда собеседник ответит в Telegram, ответ появится в чате в течение нескольких секунд.

Сборка: `npm run build`, предпросмотр сборки: `npm run preview`.

## Структура

```
src/
  api/api.ts                    запросы к GREEN-API
  store/store.ts                состояние приложения (Zustand)
  types.ts                      типы
  utils.ts                      вспомогательные функции
  hooks/useIncomingMessages.ts  получение входящих сообщений
  components/                   экраны и части интерфейса
```

## Как это работает

- Запросы строятся по шаблону `{apiUrl}/waInstance{idInstance}/{метод}/{apiTokenInstance}`.
- Чат создаётся методом `checkAccount`: он принимает номер или `@username` и возвращает `chatId`. Дальше все сообщения отправляются по этому `chatId` методом `sendMessage`.
- Пока открыт чат, хук `useIncomingMessages` в цикле вызывает `receiveNotification`. Из уведомлений берутся только текстовые сообщения от выбранного собеседника, а каждое обработанное уведомление удаляется через `deleteNotification`, чтобы оно не пришло повторно.
- При смене чата или выходе цикл останавливается через `AbortController`.
- Отправленное сообщение сразу появляется в чате со статусом «отправляется», затем меняется на «отправлено» или «не отправлено».

## Ограничения

- Только текст, без файлов и групп.
- Уведомления от других собеседников удаляются и в интерфейс не попадают: приложение показывает один чат.
- Если номер скрыт настройками приватности Telegram, найти аккаунт по номеру не получится, тогда можно использовать `@username`.
- Токен хранится в localStorage браузера. Для реального продукта запросы лучше пускать через свой сервер.
